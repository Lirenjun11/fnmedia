# 元数据

## 元数据（P0 低风险）

只做纯文本映射与清洗，**不新增任何网络请求、不引入 subprocess、不改动播放元数据常量**：

- CMS 返回的简介与分类会清洗 HTML 标签 / 实体并保留段落换行；`vod_time` 更新时间落地到详情。
- 详情页 `genres` 由 `type_name` 拆分，简介不再截断，主演 / 导演 / 更新时间分行展示。
- 搜索卡片简介清洗后放宽到 1000 字（保留上限，避免 TV 端超长文本）。
- `files[].file_name` 后缀按首选线路首集 URL 推导 `m3u8` / `mp4`，不再恒为 `.m3u8`。
- **保持不动**：`duration` / `runtime` / `resolution_type` / `width` / `height` / `bps` / `codec_name` 等仍是兼容常量。真实播放元数据探测属于后续阶段（清单文本解析 + 播放后懒回填），需先评估对官方续播判定的影响。

## 官方元数据借用（阶段 2）

在线条目自动与本地媒体库的刮削结果关联（`proxy/borrow.py`，以 `mode=ro` 只读打开官方 `trimmedia.db`，不写不锁）：

- 匹配规则：规范化标题（忽略标点 / 全半角 / 繁简差异的模糊比对）+ 年份 ±1；未命中静默回退 CMS 数据
- 命中后详情页获得：横版高清背景图（`backdrops` + 真实宽高）、官方 logo、简介、评分、时长、IMDb ID（详情页自动出现 IMDb 链接）、官方分类 ID（客户端渲染成中文分类）
- 演职人员接口 `person/list` 优先返回官方刮削数据（带头像与饰演角色）；未命中回退 CMS 演职人员拆分
- 官方图片为相对路径，客户端统一拼 `/v/api/v1/sys/img` 前缀访问，无需拷贝文件
- 海报代理与清单/直链代理共用 `allow_intranet` 策略：默认允许局域网 / 回环图片地址，可在设置关闭
- 开关：`borrow_official`（默认开启；仅读本地库，无任何网络请求）
- `deploy/db_probe.py` 可只读输出官方库结构与分类映射，用于诊断与字段核对
- 保持不动：`duration` / `resolution_type` 等播放元数据仍为兼容常量（真实探测属后续阶段）

## TMDB 元数据富化（阶段 3，可选、默认不外连）

`proxy/tmdb.py`：按「规范片名 + 年份」匹配 TMDB，只读 `api.themoviedb.org` 与
`image.tmdb.org`，**未填 API Key 时整条链路短路，不产生任何网络请求**。

- 配置（`state/config.json`）：`tmdb_enabled`（默认 `true`）、`tmdb_api_key`（默认空，
  只存本机、不入包、不上传）、`tmdb_proxy`（TMDB 专用出口代理，留空回退
  `source_proxy`，再直连）
- 判定顺序：先按分类名区分电影 / 剧集（`动作片`、`动画电影` → 电影；
  `国产剧`、`动漫`、`综艺` → TV），分类名判断不出时回退条目的 `is_tv`
- 匹配规则：先去掉 `【高清】`、`·正片`、`国语版`、`(2021)` 等展示后缀，再按
  规范化片名 + 年份打分；**片名必须有交集**才采用，年份只用于同名结果排序
  （比"年份相符即采用"更保守，避免套错成另一部电影）
- 富化内容：中文简介、类型（并入简介的「分类：」行）、评分、时长、原名、
  完整上映日期、竖版海报与 **16:9 横版背景**、演员表与导演
- 缓存：`state/tmdb_cache.json`，命中保留 **7 天**，未命中/失败负缓存 **15 分钟**；
  上限 2000 条，超出按时间淘汰
- 时效：详情接口**命中立即返回**；未命中后台富化并最多等 **1 秒**，超时先返回
  源站数据，后台补完写缓存，下次进入即完整。继续观看/播放历史列表只读缓存
  （零网络），未命中的丢后台预热，列表本身不被拖慢
- 优先级：官方库刮削（`borrow_official`）仍优先，TMDB 只参与/兜底；`genres`
  保持整型数组契约不变（类型名放简介），季/集数仍用源站结构，避免客户端
  去找不存在的季
- 图片统一走本站 `/online/<token>.jpg` 代理（图床有 Referer 防盗链）
- 设置页「TMDB 元数据」提供 Key、出口代理、开关与**测试连接**（实际请求一次
  `/configuration`，返回耗时与所用通道）
- 已知边界：TMDB 在中国大陆常无法直连，需在 `tmdb_proxy` 填可用代理；脚本
  运行时本机没有该代理则富化静默跳过，详情回退源站数据
